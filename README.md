# GAIN 2026 Pilot Desk

Tester desk for the GAIN 2026 survey pilot (EGRISS). Six case folders, each with a fictional persona's paperwork, plus a clock, pause log and debrief.

Live page: https://mitrovif.github.io/GAIN-pilot-desk/

**Survey link:** edit `SURVEY_URL` near the top of the script in `index.html`.
Debrief notes stay in each tester's own browser; nothing is sent anywhere.
